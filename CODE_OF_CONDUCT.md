# Code of Conduct

## The short version

Be decent. Argue with the design, not the person holding it.

## What we expect

- Assume the other person read the specification and disagrees for a reason.
- Disagree with evidence: a test case, a counter-example, a measurement.
- Accept a decision once it is settled and recorded in an ADR, or reopen it with new
  evidence rather than by repeating the argument.
- Keep criticism about the work. "This rule breaks case X" is useful; a remark about
  the author is not.

## What is not acceptable

Harassment, insults, personal or political attacks, publishing private information,
sexualised language or imagery, and sustained disruption of a discussion.

## Scope

Issues, pull requests, discussions, and any space where someone is representing this
project.

## Enforcement

Report a problem privately by opening a
[security advisory](https://github.com/junixlabs/traceos/security/advisories/new),
which is the only private channel this repository has. Reports are read by the
maintainers and kept confidential.

Maintainers may edit, hide or delete contributions that violate this document, and
may block a participant from the project. Enforcement decisions are explained to the
person affected.

Adapted in spirit from the [Contributor Covenant](https://www.contributor-covenant.org),
rewritten for this project.
